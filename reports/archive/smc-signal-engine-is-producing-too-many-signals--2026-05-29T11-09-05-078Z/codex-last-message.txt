**Root Cause / Analysis**

`post_ea_signal_candidates()` was persisting every valid MT5 candidate and only classifying Pine drift. There was no lifecycle gate to block a new candidate while the prior candidate for the same symbol/range was still active.

**Patch Plan**

Kept the patch backend-only and schema-free. The new gate checks the latest same-range MT5 candidate, then suppresses only when backend authority proves the prior one is still active: live pre-entry snapshot, live matching open position, or live matching pending order. Unresolved/stale authority fails open.

**Acceptance Criteria**

- Same-range duplicate candidate is suppressed while prior signal is still pre-entry valid.
- Same-range duplicate candidate is suppressed while a matching live MT5 open position exists.
- Same-range duplicate candidate is suppressed while a matching live MT5 pending order exists.
- New same-range candidate is accepted once entry is crossed and no fresh matching live trade exists.
- Stale/missing authority does not suppress.
