**Root Cause / Analysis**

The Phase 1 intake path accepted market-stream data but did not persist backend-authoritative trade telemetry for positions, pending orders, and account metrics, so the dashboard still depended on legacy/non-authoritative paths for key trade-state views. The patch adds Phase 2 telemetry ingestion, persistence, read endpoints, and frontend rewiring without weakening stale-data or backend-truth boundaries.
