**Objective**
Patched the live-signals freshness regression without changing backend snapshot authority. The work is on branch `codex/smc-intake-investigate-a-signal-freshness-regres`, commit `a9a7cbe`, PR [#283](https://github.com/klintaruvinga-png/smcsmartfib-WebApp/pull/283).

**Root Cause / Analysis**
- `/live-signals` returned a normal success response with no explicit anti-cache headers.
- `apiClient.getLiveSignals()` was not using the existing `cacheBust` + fetch `no-store` path.
- `useLiveSignals()` inherited the global `staleTime: 10_000`.
- `ensure_engine_snapshot()` was confirmed as backend authority and was left unchanged.

**Patch Plan**
Applied the narrow contract only: harden the origin response, harden the live-signals client request, harden the live-signals query freshness, then add regression tests and required reports.
